앱스토어 리뷰 데이터 분석 스크립트 실행 방법
============================================

PowerShell에서 한글 경로 문제로 인해 직접 실행이 어려울 수 있습니다.
다음 방법 중 하나를 사용하여 실행하세요:

방법 1: 파일 탐색기 사용 (권장)
--------------------------------
1. 파일 탐색기에서 이 폴더를 엽니다
2. 폴더 주소창에 "cmd" 또는 "powershell"을 입력하고 Enter
3. 나타나는 명령 프롬프트/PowerShell에서 다음 명령 실행:
   python analyze_reviews.py

방법 2: 배치 파일 실행
----------------------
1. run.bat 파일을 더블클릭하여 실행

방법 3: Python IDLE 또는 다른 IDE 사용
---------------------------------------
1. analyze_reviews.py 파일을 Python IDE(예: VS Code, PyCharm)로 엽니다
2. F5 키를 눌러 실행하거나 "Run" 버튼 클릭

실행 후 생성되는 파일:
- reviews_us.json: 미국 리뷰 데이터
- reviews_kr.json: 한국 리뷰 데이터  
- reviews_analysis.xlsx: 통합 분석 결과 (Excel)

상세 분석을 원하시면:
- detailed_analysis.py 파일을 실행하세요
