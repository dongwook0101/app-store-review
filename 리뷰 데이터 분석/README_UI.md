# 앱스토어 리뷰 분석 웹 UI

Streamlit을 사용한 사용자 친화적인 웹 인터페이스로 앱스토어 리뷰를 쉽게 분석할 수 있습니다.

## 설치 방법

```bash
pip install -r requirements.txt
```

## 실행 방법

### 방법 1: 배치 파일 실행 (가장 간단) ⭐

**`run_ui.bat`** 파일을 더블클릭하여 실행하세요.

### 방법 2: 명령어로 실행

```bash
streamlit run app.py
```

**브라우저가 자동으로 열리지 않으면:**
- 브라우저를 열고 다음 주소로 접속하세요:
  ```
  http://localhost:8501
  ```
- 또는:
  ```
  http://127.0.0.1:8501
  ```

### 방법 3: 수동으로 브라우저 열기

1. PowerShell이나 명령 프롬프트에서:
   ```bash
   streamlit run app.py
   ```
2. 터미널에 표시된 주소를 복사합니다 (예: `http://localhost:8501`)
3. 브라우저를 열고 해당 주소를 입력합니다

## 문제 해결

### 브라우저가 자동으로 열리지 않는 경우

1. **수동으로 브라우저 열기:**
   - 브라우저를 엽니다 (Chrome, Edge, Firefox 등)
   - 주소창에 `http://localhost:8501` 입력 후 Enter

2. **포트가 사용 중인 경우:**
   - 다른 포트로 실행:
     ```bash
     streamlit run app.py --server.port 8502
     ```
   - 브라우저에서 `http://localhost:8502`로 접속

3. **방화벽 문제:**
   - Windows 방화벽에서 Python을 허용하도록 설정

## 사용 방법

1. **앱 ID 입력**: 사이드바에서 앱스토어 앱 ID를 입력하세요
   - 앱스토어 URL에서 ID를 찾을 수 있습니다
   - 예: `https://apps.apple.com/app/id1510564828` → ID는 `1510564828`

2. **분석 옵션 선택**:
   - 분석할 국가 선택 (미국/한국)
   - 최대 페이지 수 설정

3. **분석 시작**: "분석 시작" 버튼을 클릭하세요

4. **결과 확인 및 다운로드**:
   - 평점 분포, 통계 정보 확인
   - 년도별 분석 확인
   - Excel, CSV, JSON 형식으로 다운로드

## 기능

- ✅ 앱 ID만으로 간편하게 분석
- ✅ 미국과 한국 리뷰 동시 분석
- ✅ 실시간 진행 상황 표시
- ✅ 평점 분포 시각화
- ✅ 국가별 비교 분석
- ✅ 년도별 분석 (리뷰 수, 평균 평점 추이)
- ✅ 다양한 형식으로 데이터 다운로드 (Excel, CSV, JSON)
- ✅ 평점, 국가, 년도별 필터링

## 주의사항

- iTunes RSS API를 사용하므로 각 페이지당 최대 50개의 리뷰를 가져올 수 있습니다
- API 호출 간 딜레이가 있어 많은 페이지를 요청하면 시간이 걸릴 수 있습니다
- 일부 앱은 리뷰가 없을 수 있습니다
- Excel 다운로드 시 타임존 정보는 자동으로 제거됩니다
